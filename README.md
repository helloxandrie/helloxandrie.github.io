# Xandrie Labilles — portfolio redesign

Open `index.html` in a browser to view the website. Keep `style.css`, `script.js`, and the `assets` folder together with it. No installation or build is needed.

The redesign includes your original portraits and work samples, six services, client testimonial excerpts, expandable project details, FAQs, and your existing booking, email, and phone links. Google Fonts loads when connected to the internet; local fallback fonts are included in the styling.

## Publish on GitHub Pages

Replace the website files in the folder currently used by your GitHub Pages site with `index.html`, `style.css`, `script.js`, and `assets/`. Preserve unrelated repository files and any custom-domain configuration. Commit the changes to the branch/folder configured under your repository’s Settings → Pages. This will replace the current Canva redirect once GitHub Pages finishes publishing.

The existing live portfolio has not been changed. This package is the complete static redesign, ready to publish.
